# Student Management System

A simple command-line Student Management System built with Python.

This project was developed in 3 versions to practice Python fundamentals, data structures, functions, input validation, and file handling.

## Features

- View all students
- Add a new student
- Delete a student using Student ID
- Search a student using Student ID
- Update student details
- Automatic unique Student ID
- Input validation
- Save student data to a text file
- Load student data when the program starts
- Data remains available after restarting the program

## Student Information

Each student contains:

- Student ID
- Name
- Age
- Course
