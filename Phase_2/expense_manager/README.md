# Personal Expense Manager

A Python-based expense management application built as part of my Python learning journey.

## Phase 2 - Intermediate Python

This project is being developed in three versions:

- Version 1 - Basic
- Version 2 - Intermediate
- Version 3 - Final

---

## Version 1 - Basic

Features:

- Add expenses
- View expenses
- Calculate total spending
- Menu-driven interface
- Basic input validation

---

## Version 2 - Intermediate

Features added:

- JSON data persistence
- Load expenses when the application starts
- Delete expenses
- Search expenses by category
- Expense numbering using `enumerate()`
- Improved input validation

Expenses are now saved in `expenses.json`, so data remains available after restarting the application.
