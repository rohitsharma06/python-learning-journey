# Quiz Game

A simple command-line Quiz Game built with Python.

This is Version 1 of the project, focused on building the basic quiz functionality using Python fundamentals.

## Features

- Display quiz questions
- Display multiple options for each question
- Accept answers from the user
- Check whether the answer is correct or wrong
- Keep track of the score
- Display the final score

## Concepts Practiced

This version helped me practice:

- Lists
- Dictionaries
- Nested data structures
- `for` loops
- `if / else`
- User input
- Variables
- Comparisons
- `len()`
- f-strings
- Basic score calculation
