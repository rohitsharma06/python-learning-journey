# Python Learning Journey 🚀

Welcome to my **Python Learning Journey**.

This repository documents my progress in learning Python through **hands-on projects**. Instead of learning only through theory, I am building practical command-line applications and improving them step by step.

Each project focuses on different Python concepts, with an emphasis on:

* Problem solving
* Writing clean and readable code
* Functions and code organization
* Input validation
* Error handling
* Data structures
* File handling
* Data persistence
* Refactoring
* Building complete working applications

The goal is to gradually move from **Python fundamentals → practical applications → advanced projects**.

```text
Basic Version
      ↓
New Feature
      ↓

      ↓
Error Handling
      ↓
Functions
      ↓
Refactoring
      ↓
File Handling / Persistence
      ↓
Final Version
```

This helps me understand not only **how to write code**, but also how to improve an existing program.
