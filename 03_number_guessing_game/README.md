# Number Guessing Game

## Version 1

### Features
- Computer generates a random number
- User guesses the number
- Displays "Too High" if guess is greater
- Displays "Too Low" if guess is smaller
- Continues until the correct guess
- Uses while loop and break

### Python Concepts Used
- Variables
- Input / Output
- if / elif / else
- while loop
- break
- random.randint()
- Comparison Operators

## Version 2

### New Features
- Added attempts counter
- Displays total attempts after guessing correctly

### New Concepts Learned
- Counter Variable
- += Operator
- f-string

## Version 3

### New Features
- Added maximum attempts
- Game Over message
- Displays attempts left after every guess

### New Concepts Learned
- Game Logic
- Limiting Attempts
- break Statement

## Version 4

### New Features
- Added difficulty selection
- Easy Mode (10 Attempts)
- Medium Mode (7 Attempts)
- Hard Mode (5 Attempts)

### New Concepts Learned
- Multiple Conditions
- Difficulty Selection
- Dynamic Variables

## Version 5

### New Features
- Added Play Again option
- Multiple games can be played without restarting the program

### New Concepts Learned

- Outer Loop
- Inner Loop
