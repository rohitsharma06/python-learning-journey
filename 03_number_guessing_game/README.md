# Number Guessing Game

## Version 1

### Features
- Computer generates a random number
- User guesses the number
- Displays "Too High" if guess is greater
- Displays "Too Low" if guess is smaller
- Continues until the correct guess
- Uses while loop and break

### Python Concepts Used
- Variables
- Input / Output
- if / elif / else
- while loop
- break
- random.randint()
- Comparison Operators
